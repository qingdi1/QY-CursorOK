安装指南

下载青云currsor小助手，完成本地初始化并验证运行状态。

下载应用

前往 最新版本页面，下载适用于 macOS、Windows 或 Linux 的安装包。优先使用最新正式版本。

首次启动

打开 Cursor 配置

启动应用后进入 Cursor 配置。如果本地 CA 尚未初始化，页面会显示初始化入口。

初始化本地 CA

点击 初始化 CA。本地 CA 用于在你的设备上解析 Cursor 发出的 HTTPS 请求，其文件只保存在本机。系统要求授权时，按照应用显示的说明在终端中完成信任操作，然后返回应用点击 我已初始化，刷新。

添加第一个模型

点击 添加模型。推荐选择常用预设中的 青云聚汇，服务器地址填写 https://api.qinggekeji.top，再填入 API Key 与模型名称。详细字段说明见 模型配置。

运行连通性测试

点击模型的 测试。测试成功后，该模型即可出现在 Cursor 的模型列表中。

首次升级或配置后完全重启 Cursor

首次升级 Cursor 或首次配置模型后，必须完全退出并重新启动一次 Cursor。仅关闭窗口不等于退出。

新建对话

Cursor 重启后新建一个对话，再从模型列表中选择你配置的模型。不要继续使用配置前已打开的对话，也不要选择 Auto。

验证安装

  • Cursor 配置页面不再显示 CA 初始化提示。
  • 至少一个模型的连通性测试成功。
  • 青云currsor小助手保持运行。
  • 已完全退出并重新启动一次 Cursor。
  • 已新建对话，而不是继续使用配置前打开的对话。
  • Cursor 模型列表中能看到配置的显示名称。

如果其中任何一步失败，请前往 常见问题。

更新

在应用设置中检查新版本，或直接访问 GitHub Releases。更新前无需删除现有模型配置。

常见问题

以问答形式解答青云currsor小助手的配置、账号、模型和 TAB 补全问题。

Q：首次升级或配置后，为什么 Cursor 提示“未登录”、看不到模型或出现 unexpected error？

首次升级 Cursor 或首次配置模型后，Cursor 需要重新建立连接。请保持青云currsor小助手运行，完全退出 Cursor 后重新启动，再新建一个对话并手动选择你配置的模型。

Q：切换到新版需要登录自己的 Cursor 账号吗？

不需要。可以在没有 Cursor 账号的情况下使用自己的模型；不过建议登录任意账号，以便使用官方插件、MCP、Skills、代码库索引和官方模型。

Q：旧版已经打开的对话可以继续使用吗？

旧助手产生的对话无法直接续接，需要新开一个对话。新版产生的对话与 Cursor 官方同步，可以在本地模型和官方模型之间切换。

Q：新版支持 Cursor 官方模型吗？

支持。官方模型仍由 Cursor 官方服务处理，自己配置的模型则通过青云currsor小助手转发。

Q：为什么选择 Auto 会提示额度或账号错误？

Auto 只会使用 Cursor 官方模型，不会自动使用你配置的本地模型。账号没有官方额度时，请手动选择自己的模型。

Q：Cursor 的插件、MCP、Skills 和代码库索引还能使用吗？

可以。登录任意 Cursor 账号后可以继续使用这些官方功能。代码库索引使用 Cursor 官方索引服务，需要将 Cursor 升级到最新版。

Q：语意搜索第一次使用为什么比较慢？

首次调用语意搜索时，应用会自动下载 Embedding Model。下载完成后，后续搜索会直接使用本地模型。

Q：TAB 补全在哪里设置？

在 系统设置 → TAB 设置 中选择：

  • 直连：连接当前 Cursor 账号对应的官方 TAB 服务（默认）。
  • 自定义：连接你自己额外部署的 TAB 补全服务。

当前二改版本不再提供原作者公益 TAB 服务。模型对话推荐使用 青云聚汇。

Q：为什么模型测试通过了，Agent 请求仍然失败？

模型测试只验证基础连接。请检查上游是否支持工具调用、上下文窗口和最大输出 Token、协议与地址是否匹配，以及调用详情中的上游状态码。

Q：本地 CA 是什么？初始化失败怎么办？

本地 CA 用于解析 Cursor 发出的 HTTPS 请求，相关文件只保存在本机。进入 Cursor 配置，点击初始化 CA，按提示完成信任，然后点击“我已初始化，刷新”。如果状态没有更新，请完全退出并重新启动青云currsor小助手。

Q：模型连通性测试失败怎么办？

  • 认证错误：确认 API Key 有效，并且账户有权访问目标模型。
  • 接口不存在：确认模型类型、请求协议和服务器地址匹配。
  • 模型不存在：使用“获取模型”检查上游返回的模型标识。
  • 参数错误：暂时移除自定义 Headers 和额外参数后再测。
  • 连接超时：检查网络、系统代理和上游服务状态。

Q：还在使用旧版生成的 fake 账户怎么办？

在 Cursor 中退出旧版 fake 账户，然后登录任意 Cursor 账号，或保持未登录状态使用自己的模型。

Q：推荐使用哪个模型服务？

推荐使用青云聚汇：https://api.qinggekeji.top。在模型预设中选择“青云聚汇”，填入控制台里的 API Key 即可。

Q：遇到其他问题时，需要提供什么信息？

请在 GitHub Issues 提交问题，并附上操作系统、青云currsor小助手版本、模型类型、请求协议、已脱敏的服务地址、错误信息和复现步骤。请勿公开 API Key 或其他凭据。
